# Конструктор SLA-соглашений

Веб-сервис для пошагового составления SLA-договора с автоматической проверкой существенных условий в соответствии с российской доктриной гражданского права.

## Технологии

- Python 3 + Flask
- python-docx — генерация .docx
- Vanilla JS + Tailwind CSS — фронтенд

## Запуск локально

\`\`\`bash
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
pip install -r requirements.txt
python app.py
\`\`\`

Сервис будет доступен по адресу http://localhost:5000
